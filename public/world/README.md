# World screenshot assets

Place administrator-approved Celenas Minecraft screenshots in this directory.
Use descriptive, lowercase filenames (for example, `moonlit-harbor.webp`) and
prefer optimized WebP or AVIF images with a landscape composition.

After adding an image, add its relative public path, meaningful alt text, and
approved caption to `gallery.images` in `src/content/home.ts`. Do not add
placeholders, stock images, or images that imply an unconfirmed server feature.
